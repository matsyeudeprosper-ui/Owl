# E011 — Independent validation of the frozen Owl strategy on pre-R0 Exness history

Proposed by ChatGPT, executed by Claude Code. Production untouched
throughout. Eras V2/V3/V4 were frozen in `DATA_ERAS.md` (commit 64c84c2)
before any download of the older years or any P&L. Order V2 → V3 → V4,
no change between eras, no rescue on any era. Inventory and the
July–September overlap validation are in `INVENTORY.md`.

Frozen strategy: candle-close FLIP-BOS + candle-close continuation, 2h
awake gate, pending-dot SL, TP 0.8R, one base position, fixed 0.02,
min_dist 10, tick execution (1 s poll) with the ACTUAL historical
bid/ask. Structure engine on M1 bars built from bid ticks (this
reproduces the R0 reference: +$238 vs +$237). Scripts: `e011_run_era.py`
(era report), `e011_control.py` (random-direction control),
`exness_import.py` (archive importer with SHA-256).

Reference: R0 (2026-07-01 → 09-08, MT5) +$237 on 524 trades, PF 1.28,
maxDD $83; V1 (09-08 → 09-11) −$26 on 47.
