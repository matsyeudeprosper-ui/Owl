# E012 — Higher-timeframe context before an M1 BOS entry vs TP-first / SL-first (2026-09-12)

Light study run beside the E011 imports (M1 arrays only, no ticks, no
V3/V4). Trades = the frozen R0 list from the tick baseline (524; TRAIN
259 / TEST 265, split 2026-08-04 21:53) and the consumed V2 list (1136,
historical replication only, NOT blind; HTF built from the archive M1).
Script `e012.py`, full tables `results_e012.txt`.

HTF = M5/M15/H1 from bid M1; at an entry on signal bar tb only candles
completed by tb+60 are used. The same structure engine (`bt_bos.Struct`)
runs on each timeframe and provides the trend state, the last confirmed
BOS, the last flip/CHoCH and the confirmed swing levels (the pending-dot
levels it confirms). All buckets, the recent = ≤ 3 bars rule, the room
boundary at 1.0 and the thirds were fixed before results.

One data limit: on 69 days of R0, H1 confirms only 2 swing highs and 7
swing lows, so "H1 room" and "recent H1 event" have almost no sample;
M15 (6 600 bars) and M5 carry the H1-style questions.

## Part 0 — stop distance by ordinal (R0 gated list)

| | TRAIN n / stop median (q25–q75) / TP-first / exp R | TEST n / stop median / TP-first / exp R |
|---|---|---|
| FLIP-BOS | 147 / 147 (91–256) / 57.8% / +0.03 | 156 / 138 (83–251) / 55.1% / −0.01 |
| 1st continuation (ordinal 2) | 41 / 161 (120–290) / 63.4% / +0.13 | 54 / 168 (122–334) / 63.0% / +0.13 |
| ordinal 3 | 35 / 128 (96–255) / 68.6% / +0.23 | 27 / 198 (161–277) / 81.5% / +0.47 |
| ordinal 4+ | 36 / 155 (114–219) / 44.4% / −0.21 | 28 / 167 (107–286) / 50.0% / −0.11 |

Early BOS trades do NOT have structurally closer stops. The flip has the
narrowest stop of all (median 138–147 pt); continuations sit at 128–198
pt with no ordinal trend. The 2nd/3rd trades are the best in both halves
(as in E007), the 4th+ the worst, and stop width is not what separates
them.

## Family 2 — recent HTF BOS / CHoCH: no sample

"Recent" (≤ 3 completed bars) aligned or opposing M15/H1 events occur
before 1–9 R0 trades per cell; 92–100% of trades sit in "stale". On V2,
M15 recent-opposing flips lose (42% TP-first, n 19) and H1 recent-aligned
continuations win (63%, n 16), but the R0 cells are empty, so nothing can
be confirmed or denied. Not testable at this sample size with this
engine on these timeframes.

M15 alone: flips with an obstacle inside half the TP distance go 91% →
53% → 59% (TRAIN → TEST → V2); continuations 47% → 72% → 64%. The
economic hypothesis (obstacle before TP ⇒ failure) is not supported in
any period; on TEST and V2 the trades with the nearest HTF obstacle are
among the better ones. A confirmed swing nearby means price is close to
structure, and that is where this strategy's trades are formed.

## Family 4 — position in the 20-bar HTF range: inconsistent

H1 thirds (favourable = plenty of room in the trade direction): flips
TRAIN 59 / 53 / 61% (fav / mid / unfav), TEST 51 / 47 / **65%**, V2 45 /
53 / 52%; continuations TRAIN 69 / 61 / 56%, TEST **85** (n 13) / 72 / 57%,
V2 54 / 51 / 53%. Flips do better when entered near the "wrong" end of the
range (breakouts), continuations when there is room, and both effects
vanish on V2. Nothing to keep.

## Candle shape (descriptive)

TP-first and SL-first trades have the same last-completed M15/H1 candle
statistics in every period (direction agreement 45–55% both, body/range
≈ 0.5 both, wick ratios ≈ 0.25 both). Not shown in detail; see
`results_e012.txt`.

## Logistic regression (frozen on TRAIN, predeclared variables only)

Variables: aligned count, recent aligned / opposing M15-H1 BOS, min room
< 1, room none, H1 favourable / unfavourable third, flip indicator.

| | AUC | Brier (vs base rate) | quintile 1 → 5 TP-first |
|---|---|---|---|
| TRAIN (fit) | 0.569 | 0.2398 (0.2431) | 46 / 56 / 63 / 61 / 65% |
| TEST (blind) | **0.499** | 0.2457 (0.2421) | 64 / 53 / 55 / 65 / 52% |
| V2 (historical) | 0.504 | 0.2560 (0.2498) | 54 / 49 / 50 / 52 / 53% |

Outside the fitted half the model is a coin flip and its Brier score is
worse than predicting the base rate. The highest-quality quintile is not
better than the lowest on TEST (52% vs 64%) or V2 (53% vs 54%).

## Answers

1. Early BOS / first continuation with smaller stops? No. Flips have the
   narrowest stops; continuation stop width does not depend on ordinal.
2. HTF alignment predicts TP-before-SL? No (sign flips, V2 flat).
3. Recent aligned M15/H1 BOS or CHoCH? Untestable: 1–9 trades per cell
   on R0; V2 hints are contradictory.
4. HTF obstacle before TP predicts failure? No; on TEST and V2 those
   trades were better, not worse.
5. HTF range position? Inconsistent across halves, flat on V2.
6. Consistent TRAIN → TEST effects? None.
7. Same direction on V2? None.
8. Weak BOS identifiable before entry better than chance? Not with these
   variables: AUC 0.50 out of sample.
9. One HTF rule worth forward observation? No.
10. HTF context adds no reliable predictive information here.

**Verdict: C.** Nothing to forward-watch, nothing to deploy. Production
unchanged.
